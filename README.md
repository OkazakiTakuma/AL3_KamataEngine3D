# 10月分
## 操作方法
AD及び左右キーで移動、Wと上キーでジャンプ<br />
Spaceキーで攻撃ができ敵に当たるとクラッシュする
## 成果
- 自キャラ操作
  - 左右の移動とジャンプを実装
- 二段ジャンプ
  - 空中にいる時にもう1度ジャンプができる
- デス演出
  - プレイヤーと敵がふれると放射状に球が出てくる
- 基本の雑魚敵
  - 左方向に移動する、好きなところに何体でも配置できる
# 11月分
## 操作方法
AD及び左右キーで移動、Wと上キーでジャンプ、はしごがあるところでWSか上下キーで昇降移動<br />
Spaceキーで向いている方向に攻撃ができ当たると敵が少し止まってから消える
## 成果
- はしごの昇降
  - 自機の中心がはしごに触れているときにWSもしくは上下キーを押すと上下に移動ができる
  - はしご専用のモデルを設定してブロックの種類ごとに描画を切り替えた 
- 崩れる床の実装
  - 自機が乗ると3秒後に消えるブロック(最上段のはしごの隣にある2つのブロック)
- 敵と自機の攻撃との当たり判定
  - Spaceキーで向いている方向に攻撃ができ最も近い敵に当たると消える
- ゴ－ルの作成
  - ゴールに触れるとフェードに入ってタイトルに戻る
  - 見た目はまだない

- すべる床
  - すべる床(白い床)の上にいる時だけ慣性が強くなる
  ## その他
  床などのモデルを自作の物に変更
  プレイヤーのジャンプが出たりでなかったりする現象が発生してる<br />
  攻撃範囲のモデルがなくて範囲がわかりづらいのでモデルを作成してわかりやすくする<br />
  はしごの頂点でジャンプが出なかったり、登るのをやめると少しづつ落下したりする<br/>
