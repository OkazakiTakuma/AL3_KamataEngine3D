# 11月分
## 操作方法
AD及び左右キーで移動、Wと上キーでジャンプ、はしごがあるところでWSか上下キーで昇降移動<br />
Spaceキーで向いている方向に攻撃ができ敵に当たるまで判定が残る
## 成果
- はしごの昇降
  - 自機の中心がはしごに触れているときにWSもしくは上下キーを押すと上下に移動ができる
  - 梯子専用のモデルを設定してブロックの種類ごとに描画を切り替えた 
- 崩れる床の実装
  - 自機が乗ると3秒後に消えるブロック
- 敵と自機の攻撃との当たり判定
  - Spaceキーで向いている方向に攻撃ができ最も近い敵に当たると消える
  - 本来なら敵と当たらなかったら攻撃処理を無くすはずが攻撃処理が残っている
  ## その他
  プレイヤーのジャンプが出たりでなかったりする現象が発生してる
